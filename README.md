# site-vitrine-cinetica
Repositório GitHub criado para projeto acadêmico para auxiliar o aprendizado e o desenvolvimento dos processos da Cinética Jr, como versionamento do código com Git e GitHub, automações com n8n e páginas web.

Projeto modelo de formulário online para envio de email.

## Detalhes técnicos:
O projeto foi desenvolvido utilizando HTML e CSS para a criação e estilização da página web, com o Visual Studio Code como editor de código. O Git foi utilizado para o controle de versionamento do projeto, enquanto o GitHub foi utilizado como repositório em nuvem para armazenamento e gerenciamento do código. Durante o desenvolvimento, foi utilizado o Live Server para executar e visualizar a página localmente em tempo real. Para a automação de processos, foi utilizado o n8n, hospedado em um ambiente Docker, que possibilita a execução do serviço de forma isolada e organizada.
